# 条款口径

T2b（条款树切分）的验收标准。规则写不清，切完无法判断对错。四条规则 + 一条评测口径。

实测依据：三份样本共 8618 行、6511 个文字块，块均 1.3–1.4 行（块≈行），无编号行占 76%–83%。

---

## 一、一条条款的边界

- 起点：一个条款起点行（见第二节）。
- 终点：下一个条款起点行**之前**的最后一块。
- 中间的空行、续行、表格、图片说明都归这一条。
- 允许跨页：`page_start` / `page_end` 分开记，`bbox` 取首块，`continued=true`。
- 没有起点行的连续块（如封面、目录、附件说明）：不切，整段归上一条，标 `kind=block`。

## 二、条款起点判定

**先探测本文档用哪套编号，再套优先级。** 三份样本实测用了三套，写死一档必错：

| 文档 | 主力档 | 次要档 | 几乎不用 |
|---|---|---|---|
| beijing_road | `X.Y.Z` 5.2% + `X.Y` 7.9% | `1.` 4.9%、`（1）` 2.7% | `第X条` 0.8% |
| chongzuo_green | `1.` 7.8% | `（1）` 5.0%、`X.Y` 5.4%（含误报） | `第X条` 0 |
| wenling_video | `1.` 8.8% | `一、` 2.4%、`（1）` 2.6% | `X.Y` 0.7% |

**探测方法**：统计全文八档编号的命中率，取命中最多的两档作为本文档的「起点档」；某档不到 2% 就不进起点档。

**档位优先级**（同档内按此顺序）：

1. `第X条`（`第一条`、`第 12 条`）
2. `X.Y.Z` / `X.Y`（`5.2.5`、`12.1`）
3. `（一）` / `（1）`
4. `①`
5. 字号 ≥ 正文号 × 1.1 且独立成行的块（标题样式）
6. 都不满足 → 不切，归上一条，`kind=block`

**正则必须收紧**：编号后必须紧跟中文或空白。`\d+\.\d+` 会把 `2263.76` 这类金额当成 `X.Y`（崇左实测有误报），也不能匹配到 `元/万/亿/%/个/年/月/日` 结尾的句子。

**正文号怎么定**：全文按字数加权取字号众数（实测 beijing 12.0、chongzuo 10.4、wenling 11.1）。

## 三、表格怎么算

- 抽取单位是**行**，不是句子：一个评分项 = 一行；单元格不单独成条款。
- 表格块不参与条款切分，单独走 `tender/tabular.py`，产物是 `Table(page, rows, cols, cells, bbox)`。
- 跨页表：下一页首块不是表头、且列数与上页相同 → 接续为同一张表，`continued=true`。实测三份样本贴页边的表 11 / 18 / 15 张，不能不管。
- 评分表认定：列头含「分值」「评分因素」「评分标准」任一。

## 四、失败回退

| 情况 | 处理 |
|---|---|
| 无编号、无字号线索 | `kind=block`，仍出块级框，照旧进表 |
| 扫描件 / 图片页 | 不在本版范围（实测 0 页），遇到时整页标 `kind=block` |
| 表头缺失（跨页表第 2 页） | 继承上页列数，列名标 `inherited` |
| 页码拿不到 | 标「人工看」，不猜 |

## 五、评测口径

- 判分用「页码 + 关键词」：`eval/questions.json` 的 `expect_pages` 与 `keyword`。可选 `expect_clause`（条款编号）供人工复核。
- **不统计框粒度**：2026-11-23 起移除 `bbox_report.py`；`bbox` 只用于解析层的几何判定（页眉页脚、表格跨页、书签范围），不参与证据定位与评分。

## 待确认（三条，需要业务判断）

1. **跨页条款的 `bbox`**：现在先采用 取整条条款的并集（框会大，但一眼能看出跨页）。这影响 UI 高亮观感，不影响数字。之后要是不合适,我会「取首块」。
2. **`（1）` 算不算独立条款**：在「投标人须知」里它常是子项（依附上级），在「评分办法」里可能是独立评分项。那就在评分办法里按章节类型区别对待,其他地方是子项
3. **附件/格式样表里的空栏**（`____`）：算条款，因为「空位对照」表就是靠它。

## 验收（T2b 做完对这四个数）

- 条款数：beijing 250–500、chongzuo 250–500、wenling 200–350
- `extract.rejects` 里 `no_evidence` 不增
- 回归跑 3 次取多数，稳定题不降
- 证据能回到**页码 + 条款编号**（人工抽查 10 条，页码与编号都对得上）
