# 招标文件竖向结构（三份样本 + 市场常见形态）

> 2026-11-21。依据 `sample/` 三份政府采购公开招标 PDF 的正文「第X章」（不以书签为准），并对照市场常见招标/磋商文本。
>
> 三份：`beijing_road.pdf`（北京东城道路监理，92 页）、`chongzuo_green.pdf`（崇左龙州八角低产林改造，105 页）、`wenling_video.pdf`（温岭雪亮工程视频接入，64 页）。

书签不能当目录：北京 99 条书签把合同「第一条」挂在第五章采购需求下；温岭全书只有 7 条书签。下文以正文「第X章」为准。

---

## 一、标准竖向骨架（市场 + 三份样本）

政府采购货物/服务公开招标，通常 **6～8 章、不分卷**：

| 序 | 功能块 | 三份出现 | 章名常见写法 |
|---|---|---|---|
| 0 | 封面 / 目录 | 3/3 | 目录（点线+页码，或只列章名） |
| 1 | 入口信息 | 3/3 | 投标邀请、招标公告、采购公告、邀请书 |
| 2 | 程序规则 | 3/3 | 投标人须知（常含「须知前附表/资料表」） |
| 3 | 资格 | **1/3 独立成章** | 资格审查；多数并进公告「申请人资格要求」+ 须知「资格审查」 |
| 4 | 怎么评 | 3/3 | 评标办法及评分标准 / 评标程序、评标方法和评标标准 |
| 5 | 买什么 | 3/3 | 采购需求、公开招标需求、项目需求、技术规格 |
| 6 | 中标后合同 | 3/3 | 拟签订的合同文本 / 政府采购合同主要条款指引 / 合同草案 |
| 7 | 投标人要交的空表 | 3/3 | 投标文件格式、响应文件格式、格式附件 |
| 8+ | 地方附加 | 崇左有 | 质疑投诉格式、政采贷、验收书格式 |

**顺序几乎固定。** 唯一例外：崇左把 **采购需求提前到须知之前**（第二章），其余仍是公告 → … → 格式。

**工程招标**（住建/九部委标准施工招标）会再分成卷：第一卷程序+合同，第二卷图纸，第三卷工程量清单，第四卷技术标准，第五卷投标格式。电子标再加「投标人须知前附表」里的解密、CA、备份标。磋商/谈判把「投标」换成「响应/磋商」，须知改「磋商须知」，评标改「评审办法」，格式改「响应文件格式」。

## 二、三份样本章级对照

| 功能 | 北京 92 页 | 崇左 105 页 | 温岭 64 页 |
|---|---|---|---|
| 公告 | 第一章 投标邀请 p3–6 | 第一章 招标公告 p3–8 | 第一章 招标公告 p3–5 |
| 须知 | 第二章 投标人须知 p7–22 | 第三章 投标人须知 p23–42 | 第二章 投标人须知（以 **前附表** 起篇）p6–17 |
| 资格 | **第三章 资格审查** p23–25 | 并入须知「五、资格审查」 | 并入公告「二、资格要求」+ 须知 |
| 评标 | 第四章 评标程序、评标方法和评标标准 p26–35 | 第四章 评标方法及评分标准 p43–49 | 第三章 评标办法及评分标准 p18–21 |
| 需求 | 第五章 采购需求 p36–43 | **第二章** 采购需求 p9–22 | 第四章 公开招标需求 p22–35 |
| 合同 | 第六章 拟签订的合同文本 p44–68 | 第五章 拟签订的合同文本 p50–63 | 第五章 政府采购合同主要条款指引 p36–39 |
| 格式 | 第七章 投标文件格式 p69–92 | 第六章 投标文件格式 p64–94 | 第六章 投标文件格式附件 p40–64 |
| 附加 | — | 第七章 质疑投诉格式；第八章 政采贷 | — |

页数上 **格式章最大**（北京约 26%、崇左约 40%、温岭约 39%），其次须知或合同。资格独立成章只有北京。

## 三、各章：小节叫什么、里面是什么

### 1. 招标公告 / 投标邀请

**小节（北京书签最完整，三份同构）：**

1. 项目基本情况（编号、名称、预算、最高限价、标段/包、简要需求）
2. 申请人资格要求（政府采购法 22 条 + 中小企业政策 + **项目特定资质**）
3. 获取招标文件
4. 投标截止、开标时间地点（电子标还有解密时限）
5. 公告期限
6. 其他补充（发布媒体、代理）
7. 联系方式

**形态：** 短条款 + **前附表式键值**（项目编号、预算金额）+ 资格用（一）（二）列举。时间、限价、是否联合体，投标人第一眼看这里。

### 2. 投标人须知（程序主干）

几乎都是 **两层：前附表 + 正文**。

**前附表 / 资料表（温岭整章开头就是「须知前附表」）：**  
三列表格：条款号 | 项目 | 编列内容。把正文里要填的数（保证金金额、有效期、是否联合体、开标方式、解密分钟）抽成一行。**短文字 + 表格，信息密度最高。**

**正文小节（北京/崇左标准结构，编号** `1.` **/** `8.3` **这种）：**

| 节 | 典型标题 | 装什么 |
|---|---|---|
| 一 | 总则 / 说明 | 采购人、联合体、现场踏勘、政府采购政策、投标费用 |
| 二 | 招标文件 | 文件构成、澄清修改（「15 日前书面通知」这类期限） |
| 三 | 投标文件的编制 | 组成、报价、**投标保证金**、有效期、签署盖章 |
| 四 | 提交 | 截止、修改撤回、电子加密/备份标 |
| 五 | 开标、资格、评标 | 开标、解密、资格审查、评委会（细则指向评标章） |
| 六 | 确定中标 | 中标公告、**废标情形**、签合同 |
| 七 | 询问质疑 | 质疑期限 |
| 八～九 | 验收 / 其他 | 代理费、地方条款 |

崇左正文用「一、总则 … 九、其他事项」，条款号与前附表「6.1」对齐。北京是「一 说明 / 1采购人… / 12投标保证金」。

**形态：** 编号短条款为主；「否则投标无效」大量出现在保证金、密封、签字、资格。政策段（中小企业、节能环保）会突然变成 **长段引用法规**。

### 3. 资格审查（有则独立，无则并入）

北京独立章：

- 一、资格审查程序（不合格 → 投标无效；合格不足 3 家不评标）
- 二、资格审查要求（**表格**：审查因素 / 审查标准 / 格式要求）

材料清单（营业执照、声明函、资质证书）往往 **须知前附表「资格证明文件组成」+ 格式章「资格证明文件格式」各写一遍。**

### 4. 评标办法

**小节几乎固定：**

1. 评标方法（综合评分 / 最低评标价）
2. 评标程序：**符合性审查**（不通过即无效）→ 澄清 → 比较评价 → 推荐候选人
3. 评标标准 / 评分表：价格部分、商务部分、技术部分（北京还分两级表头「分项/合计」）
4. 中标候选人推荐、评标报告

温岭把 **价格分公式写在散文里**（`得分=(评标基准价／投标报价)×50%×100`），表和文字并存。

**形态：** 符合性是短条款/检查清单；评分是 **表**；价格分是 **公式符号**。同一章三种载体。

### 5. 采购需求

**小节因标的而异，但层固定：**

- 一、项目概况 / 采购标的（地点、规模、范围）
- 二、商务条款（▲ 崇左明确标了商务）期限、付款、质保
- 三、技术方案 / 项目要求（规格、服务内容、人员、★▲ 实质性）
- 四、其他（验收、知识产权、原厂授权）

北京监理需求相对短（约 8 页）；崇左林改、温岭视频都是十几页，夹 **设计说明长文 + 点位/工程量表**。

**形态：** 长叙述 + 清单 + 表；「否则投标无效」的技术门槛写在这里，不在须知。

### 6. 合同文本

**小节是「第 X 条」合同体例**（北京书签误挂到第五章，正文从第六章开始）：工程概况、服务范围、酬金与支付、违约、变更、生效中止、保密、争议……温岭压缩成「主要条款指引」，空白待填合同金额。

**形态：** 长条款、履约期限（7 天内、14 天内）、履约保证金、违约金。用词像废标（拒收、无效）但阶段是 **履约不是投标**。

### 7. 投标文件格式

**先「编制须知」（短条款，含「空格不填投标无效」），再按投标文件分册给空表：**

| 分册 | 典型附件名 |
|---|---|
| 资格证明文件 | 营业执照、资格声明书、中小企业声明函、特定资质、保证金凭证/投标担保函 |
| 商务（技术）文件 | 投标书/投标函、授权委托书、开标一览表、分项报价表、合同偏离表、需求偏离表 |
| 报价文件 | 崇左单列「四、报价文件格式」 |
| 其他 | 联合体协议、无串通声明；崇左另有质疑函/投诉书格式 |

温岭用「附件 1 资格证明文件」封面式，书签几乎没有子目。

**形态：** 空表、下划线、盖章处、★实质性格式；夹一句真废标。整章像表单，不是论述。

### 8. 附加章（市场常见、样本里崇左有）

质疑函格式、投诉书、验收书、融资/政采贷告知。对投标有效性通常次要，但对「材料/空位」可能多几张空表。

## 四、须知以下的「竖」长什么样（编号体系）

三份不是同一套编号，切条款时要探测档位：

| 档 | 北京 | 崇左 | 温岭 |
|---|---|---|---|
| 章 | 第一章 | 第一章 | 第一章 |
| 须知大节 | 一 说明 / 二 招标文件 | 第一节前附表、第二节正文；正文「一、总则」 | 前附表按序号 1、2、3… |
| 条款 | 12 投标保证金、12.1 | 前附表条款号 6.1；正文 25.资格审查 | （一）（二）；1. 2. |
| 评标 | 一、评标方法；评分表行 | 第一节方法…第三节评分标准 | 一、二、（一）公式 |
| 合同 | 第一条…第十七条 | 合同条文 | 一、主要工作内容 |
| 格式 | 一、资格… 1-1 营业执照 | 一～五、分册 + 附件 | 附件 1、2… |

## 五、和市场的对应关系（扩样本时章名会变）

| 场景 | 章名怎么变 | 结构变不变 |
|---|---|---|
| 公开招标（本三份） | 投标/招标/评标 | 七块骨架不变 |
| 竞争性磋商/谈判 | 磋商公告、磋商须知、评审办法、响应文件格式 | 块还在，别名要加 |
| 工程招标 | 多出图纸、工程量清单、技术标准与要求 | **多卷**；清单是纯表 |
| 电子标 | 须知前附表加解密、.jmbs/.bfbs | 温岭已是 |
| 多标段/分包 | 公告里分标表（崇左 p4） | 需求/报价按包重复 |

资格、废标、保证金 **不会只出现在一章**：公告摘要一遍，须知写规则，评标符合性再写，格式给空表。竖向结构是「同一事项多层重复」，不是「一章一个主题切干净」。

## 六、和「内容形式」的衔接（每章主导形态）

竖向解决「到哪一章找」；同一章内部还要按形态分流（表直读、公式扫、短条款穷尽、长文才检索）。

| 章 | 主导形态 | 次要 |
|---|---|---|
| 公告 | 键值 + 短列举 | 少量日期 |
| 须知前附表 | **三列表** | 单元格里嵌长段 |
| 须知正文 | **短编号条款** | 政策长引文 |
| 资格 | 审查 **表** | 程序短句 |
| 评标 | 符合性短句 + **评分表** + **公式** | |
| 需求 | 长文 + 清单 + 表 + ★ | |
| 合同 | 长条（第 X 条） | 金额期限 |
| 格式 | **空表/填空** | 编制须知短句 |

除长文 / 短条款 / 表 / 文+表 / 数字符号外，还可补：**前附表键值、空表单、法规摘录、★▲ 标记、跨章「详见第 X 章」**。
